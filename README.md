# CLASIFICACIÓN DE EXPRESIONES EMOCIONALES MEDIANTE CNN

Desarrollo de una **Red Neuronal Convolucional (CNN)** para clasificar dibujos de caras, discriminando entre 6 categorías emocionales: **Alegría, Asco, Ira, Miedo, Sorpresa y Tristeza**.

El proyecto utiliza más de 2500 dibujos, creados en Paint, incorporando variabilidad en tamaño, posición y diversas características gráficas.

## Resultados

**Accuracy >92%** sobre el conjunto de prueba.

El modelo fue evaluado mediante **matriz de confusión** e indicadores como **Precision**, **Recall** o **F1-score**. Además, se realizan **pruebas de destreza del modelo al final del experimento, a través de 15 imágenes nuevas e independientes**, para explorar su capacidad de generalización.

## Tools

**Python**(`TensorFlow`, `Keras`, `Scikit-learn, `NumPy`, `Matplotlib`)
